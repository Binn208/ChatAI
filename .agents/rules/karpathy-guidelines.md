# Karpathy Coding Guidelines

Follow these core principles for all coding and refactoring tasks:

1. **Think Before Coding**: State assumptions explicitly. Surface tradeoffs and ask when requirements are ambiguous.
2. **Simplicity First**: Deliver the simplest working solution. No premature abstractions or speculative features.
3. **Surgical Changes**: Only modify code strictly necessary for the task. Match surrounding style. Do not refactor unrelated working code.
4. **Goal-Driven Execution**: Define concrete, verifiable success criteria before starting. Loop and verify each step thoroughly.
