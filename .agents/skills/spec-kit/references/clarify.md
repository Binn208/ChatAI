# Spec Kit: Clarification Protocol

When specifications or user requests contain ambiguity, do not assume or silently choose a path.

## Protocol
1. **Identify Ambiguity**: Pinpoint the exact missing detail (e.g., error behavior, authentication flow, layout breakpoint).
2. **Present Tradeoffs**: Give 2–3 viable approaches with their pros and cons.
3. **Recommend a Default**: Suggest the best practice or simplest option while asking the user for confirmation.
