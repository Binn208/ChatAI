# Spec Kit: Quality Checklist

Run through this checklist before marking any feature as complete:

- [ ] All Acceptance Criteria from `spec.md` are satisfied.
- [ ] Code strictly follows `constitution.md` conventions and architectural patterns.
- [ ] No extraneous files or dead code were introduced.
- [ ] All automated unit/integration tests pass.
- [ ] Error scenarios and edge cases (empty input, offline, timeouts) are properly handled.
- [ ] Documentation and user-facing walkthroughs are updated.
