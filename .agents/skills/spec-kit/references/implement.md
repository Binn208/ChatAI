# Spec Kit: Implementation Guide

The **Implementation** phase executes the task list following the Constitution, Spec, and Plan.

## Guidelines
1. **One Task at a Time**: Complete and verify a task before moving to the next.
2. **Surgical Precision**: Modify only what is specified. No stray edits.
3. **Continuous Verification**: Run the verification command specified in each task immediately after editing.
4. **Course Correction**: If implementation reveals unexpected complexity or breaks the Plan, pause and update the Plan before continuing.
